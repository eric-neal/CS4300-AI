# Game Features and Home MLB Teams Wins 
This is a revamp of my final project for the fall semester of 2021. 

This project used a very simple neural network using Keras for a binary classification model. The source of mlbgames2016 is a [dataset from Kaggle](https://www.kaggle.com/datasets/cyaris/2016-mlb-season) using data scraped from [Baseball Reference](https://www.baseball-reference.com/).

# Game Features and Home MLB Teams Wins 
Given a set of features such as attendance, errors, field type, regular vs. post-season, it is the goal to find a relationship between these and the win or loss of the home team. This is a revamp of my final project for the fall semester of 2021. 
This project uses a very simple neural network using Keras for a binary classification model. The source of mlbgames2016 is a [dataset from Kaggle](https://www.kaggle.com/datasets/cyaris/2016-mlb-season) using data scraped from [Baseball Reference](https://www.baseball-reference.com/). 
While this dataset is from the 2016 MLB season this NN can be extended to other seasons or even other leagues where the regression may be more stronger.

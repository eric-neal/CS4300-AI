# CS4300 - Predicting Next Day Rainfall in Australia
Introduction to Artificial Intelligence - University of Missouri St. Louis - Fall 2021

This is a revamp of my project for the fall semester. My original dataset and output variable and was heavily dependent on one or two features and therefore wasn't a very reliable model for learning. 


This project used a very simple neural network using Keras for a binary classification model. The source of the dataset is from [Joe Young on Kaggle](https://www.kaggle.com/jsphyg/weather-dataset-rattle-package) using [government climate data](http://www.bom.gov.au/climate/data/).
